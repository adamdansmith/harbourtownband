Add, change or archive shows in one small file. GitHub will ask you to sign in, and only people with access to the Harbour Town repository can save edits.

EDIT GIGS ON GITHUB →

Add a gig

Put another line between the square brackets. Use a date in YYYY-MM-DD format. Venue and place are required; time, venue URL and photo are optional.

{ date: '2027-05-22', venue: 'The Golden Eagle', place: 'Southsea', time: '4pm' }

Archive a gig

Past dates move to the expandable archive automatically. To move a gig there early, add archived: true to its line. To restore an upcoming date, remove it.

{ date: '2027-05-22', venue: 'The Golden Eagle', place: 'Southsea', archived: true }

Save and check

Use GitHub’s Commit changes button. The design preview will update after deployment. Check the gigs page and the homepage after saving. Keep previous shows in the file so they stay in the archive.
